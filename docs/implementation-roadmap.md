# 内部 XMind MAP 编辑器实现路线

## 范围

浏览器端单人文件编辑器：打开、编辑、保存现代 `content.json` 格式的 `.xmind`，尽可能接近官方 MAP 呈现。

支持文字、子主题与同级主题增删、层级和顺序调整、标记、图片、自由主题、折叠展开、选择、缩放平移、拖拽及撤销重做。

主图支持 `org.xmind.ui.map.clockwise` 和带有效 `right-number` 的 `org.xmind.ui.map.unbalanced`，保留下级布局依赖的 `logic.left`、`logic.right`。显式换侧时转换为 unbalanced 并维护左右分区；此编码已由官方客户端读取验证。裸 MAP 和缺省结构仍需样本确认。多 Sheet 文件保留全部内容，仅对支持的结构开放编辑。

## 架构约束

1. **文档是唯一事实来源。** 保留原始 JSON、全部 Sheet、主题 ID、未知字段及 ZIP 条目。索引、运行时模型和 SVG 均为可重建投影；不能只修改旧 `Topic._children` 后从 `_data` 保存。
2. **操作统一经过命令。** 标题、增删、移动、标记、图片和自由坐标由文档命令维护索引、引用和历史。移动需防止循环；一次拖拽提交形成一次可撤销操作。
3. **复用原 MAP 布局与 SVG。** 在现有控制器外增加适配，先补齐内容测量和样式。布局调整依据几何对照结果，不把字体或样式差异归因于算法。
4. **初期编辑提交后整图重排。** 保持视口、选择和合理的输入焦点，释放旧视图、监听器及临时资源 URL；有实际性能证据后再做局部更新。
5. **坐标分层。** 文档坐标、视口变换和导出裁剪独立。缩放平移不能改写自由主题坐标。
6. **文件格式由自己的适配层维护。** 官方生成 SDK 可作格式参考；其有限模型不用于重建已有文档，避免丢失样式、自由主题和未知字段。

```mermaid
flowchart LR
    A[原始 ZIP 与 JSON] <--> B[文档与资源]
    C[命令与历史] --> B
    B --> D[样式解析与主题测量]
    D --> E[原 MAP 布局与 SVG]
    E --> F[编辑交互]
    F --> C
```

## 功能边界

| 部分 | 实现要求 |
| --- | --- |
| 文档与历史 | 索引包含 ID、Sheet、父主题、子主题类型和顺序。撤销重做恢复文档与相关引用 |
| 文字交互 | 沿用 TypeScript/DOM 入口，使用覆盖在主题位置的 HTML 输入控件，处理中文输入法后提交命令 |
| 样式与测量 | 测量与绘制使用同一字体、字号和换行规则；字体及图片尺寸就绪后布局。处理继承、填充模式和自动配色 |
| 标记与图片 | 标记参与主题宽度；图片通过 ZIP 资源解析，宽高比、显示尺寸和相对标题的位置参与主题布局。未知标记 ID 保留 |
| 自由主题 | 独立主题树，使用保存坐标和自由主题样式；不参与主图 attached 分支分配。区分中心主题与自由树根，避免按父控制器或层级套错角色 |
| 折叠 | 完整后代保留于文档，可见布局跳过后代，更新连线、控件和画布范围。文件字段确认后由适配器读写 |
| 拖拽 | 普通主题修改层级、顺序或所属侧；自由主题写入换算后的文档坐标 |

## 保存约束

- 从文档和原 ZIP 保存，保留未修改字段、其他 Sheet 和资源内容；不能从 SVG 反推文件。
- 更新新增／修改的资源及 manifest，维护主题操作涉及的引用，包括 `arrangeableLayerOrder`。
- 资源删除以引用检查为前提。移动或删除涉及未支持的关系线、概要、边界等引用时，补齐维护或限制该操作。
- revision、缩略图和缓存按官方重新打开结果确定更新策略；不因本地布局实现而自动改写 `layoutEngineVersion`。

## 实施与验收

### 显示与视觉对照

| ID | 工作 | 完成依据 |
| --- | --- | --- |
| R1 | 样式与文字测量 | 明确使用字体，处理继承、填充及自动配色；记录与官方样本的尺寸和样式差异 |
| R2 | 标记、图片及资源解析 | 标记与图片参与主题尺寸；比例和位置正确，资源可解析 |
| R3 | 自由主题与结构规则 | 按已确认坐标显示自由树；正确选取主题角色和结构，画布不裁掉内容 |
| R4 | 建立渲染回归 | 使用固定样本和官方 JPEG，比较相对位置、主题尺寸、连线与内容排列，记录残余差异 |

### 编辑与保存闭环

| ID | 工作 | 完成依据 |
| --- | --- | --- |
| E1 | 文档、索引、命令和历史 | 增删移动及撤销重做保持 ID、原始字段、索引和引用一致 |
| E2 | 选择、文字输入及基础主题操作 | 中文输入、增删主题、刷新后的视口与选择通过浏览器验证 |
| E3 | 保存 ZIP | 保存后由官方应用重新打开；编辑结果、其他 Sheet、样式及资源保留，引用有效 |

### 日常编辑

| ID | 工作 | 完成依据 |
| --- | --- | --- |
| I1 | 折叠展开及状态读写 | 隐藏后代不占布局空间，展开可恢复；已确认的持久化字段通过官方验证 |
| I2 | 拖拽层级、顺序、左右侧和自由坐标 | 缩放平移后坐标正确，操作可撤销；保存后官方打开结果正确 |
| I3 | 标记修改、图片插入替换与缩放 | 尺寸、引用、撤销重做及保存往返一致 |

内部自动测试、官方图像对照、官方重新打开分别验收。UI 已实现但格式或官方结果未验证的项目，仍保留对应待验收项。

任务状态、下一步和未决证据见 [实施进度](implementation-progress.md)；固定输入和图像比较方法见 [样本说明](../tests/fixtures/README.md)。
