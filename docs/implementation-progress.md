## 最近验证

2026-11-17：

- UI1：React 管理工具栏、文件、工作表、文字编辑和节点控件；SVG 几何通过适配层读取，文档、命令和布局核心不变。StrictMode 下检查选择、悬浮、折叠历史、键盘焦点和视口位置；Vite 开发模式验证重复挂载后仅一个 SVG、单次点击只产生一条命令及撤销，无页面异常。自由树控件跟随实际子树方向，覆盖初始折叠的默认向右和显式向左；不涉及文件格式变更。

- R1–R3：处理 `inherited`、层级样式、无填充、自动分支色；本地加载 [NeverMind](../src/assets/fonts/nevermind/README.md)，实测中心标题宽 199.8px，官方参考图约 201px。图片与标记参与主题测量；自由树使用文件坐标并计入画布，自动色按顺序轮换。样本的图片显示 200 × 161，标题在图片下方。对照官方 JPEG 的浏览器回归约束：主分支和图片相对位置误差小于 20px，自由主题中心偏移误差小于 2px；标记图形与部分间距仍有差异。
- E1–E3：原始 JSON 和 ZIP 为事实来源；命令支持改名、增删、重排、移动、历史及保存，自动测试验证未知字段、其他 Sheet 和原资源内容保留。包含关系线、边界或概要的工作表禁止结构增删移动。保存补入新增资源的 manifest 项。官方重新打开的结果及固定综合文件见[验收记录](official-validation.md)。
- I1–I3：`branch: folded` 读写，隐藏后代不参与布局；普通主题拖至目标中部换父、上下缘调整顺序，自由主题位移经视口矩阵逆变换。主分支可拖至中心主题对应侧或用按钮换侧，转换为 unbalanced 并维护 `right-number`；官方客户端已确认该编码的读取语义。支持常见优先级、进度、旗帜、标签和表情标记，未知标记显示占位并可移除。图标是本地近似绘制；图片支持插入、替换与宽度调整。替换图片保留其未知字段；旧资源保留。
- [官方客户端验收](official-validation.md)：真实 UI 导出的综合文件在 Xmind 27.01 中正确呈现换侧、折叠、自由主题和图片尺寸。
- `npm run check:all`：19 项单元测试、19 项系统 Chromium 浏览器测试、类型检查和生产构建通过。覆盖逐条 ZIP 内容与工作表切换和保留、丰富样本、中文输入法组合、编辑时快捷保存、嵌套折叠、换侧、图片与 manifest、坏图恢复、未知标记、自由树子主题，以及 1.2 倍缩放后的自由主题拖拽和编辑前后视口位置。
